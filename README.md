# ShelfCheck releases

Installers for **ShelfCheck**, a price lookup app for shops: scan a barcode on the shop PC or a phone and see the price.

## Installing

1. Open the [latest release](https://github.com/rwahumphreys/ShelfCheck-Releases/releases/latest).
2. Under **Assets**, download `ShelfCheck-Setup-<version>.exe`.
3. Run it on the shop PC (Windows 10 or 11, 64-bit). Windows asks for an administrator's permission.

If Windows says *Windows protected your PC*, click **More info**, then **Run anyway**.

The User Guide is installed with the app (Start menu → ShelfCheck → ShelfCheck User Guide).

## Updates

Installed copies check this page for new versions and update themselves. Each release includes `latest.json`, which describes the installer, and `latest.json.sig`, a signature that ShelfCheck checks before it installs anything.

This repository only holds releases. The source code is kept elsewhere.
